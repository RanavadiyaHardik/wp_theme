How To Create A Custome Theme In Wordpress

1) Create A Folder In Xampp/htdocs/Your Wordpress Folder/wp-content/themes/
2) Create Two Files In Your Folder named 
   i) style.css  (For Style)
   ii) index.php  (For Home Page)
3) Add below code in style.css file
   /*
   Theme Name: My Theme
   Author: BCA Sem 3
   Description: Twenty Twenty-Three is designed to take advantage of the new design tools introduced in WordPress 6.1. With a clean, blank base as a starting point, this default theme includes ten diverse style variations created by members of the WordPress community. Whether you want to build a complex or incredibly simple website, you can do it quickly and intuitively through the bundled styles or dive into creation and full customization yourself.
   Version: 1.0
   */

4) Add Any Theme Code In index.php


The Usefull Functions 
    1-> echo get_template_directory_uri() -> This function is use for getting the path of your theme folder

    2-> bloginfo('template_directory') -> This function is use for getting the path of your theme folder this function is use without echo

    3-> get_header() -> This function is use for getting the header.php file from your theme folder in your index.php file.

    4-> get_footer() -> This function is use for getting the footer.php file from your theme folder in your index.php file.

    5-> get_sidebar() -> This function is use for getting the sidebar.php file from your theme folder in your index.php file.

    6-> site_url() -> This function is use for getting the website url.

Note: Create header.php and footer.php file and use get_header() and get_footer() in index.php for include header and footer

Topic 2
   How To Make Header Menu Dynamic

   1-> Create A functions.php file and use register_nav_menus() function for creating menu 
         Ex.   register_nav_menus(
                  array('primary-menu' => 'Header Menu') // You Must Pass The Array Key And Value The Value Is Shows In Admin Side
               );
   
   2-> The Menus Option Is Available In Admin Dashboard Click And Create And Edit Menu

   3-> Use wp_nav_menu() function for showing menu in front side in header.php
         Ex.   <?php
                  wp_nav_menu(array('theme_location' => 'primary-menu', 'menu_class' => 'menu')); //must pass the array 
               ?>
   
   4-> You Can Design Your Menu As You Need By Their Class Name Ex. ".menu" The Menu Is Provide <ul> <li>format


Topic 3
   How To Create Custom Page layout And Show Pages Dynamically

   1-> Create A page.php file all pages use this file 

   2-> use get_header() and get_footer() for including header and footer 

   3-> use the_title() function for getting the title of the Page

   4-> use the_content() function for showing content of the page OR if it's not working use the_post() in the top of the page.php

   5-> you can use get_the_content() function for showing the page content also but the function use echo before the function 
         Ex. echo get_the_content();

Topic 4
	How to add thumnail image or featured image in page
	1-> use add_theme_support('post-thumbnails') function in functions.php for getting image option in admin side

	2-> the_post_thumbnail(); // Without parameter ->; Thumbnail
	    the_post_thumbnail('thumbnail'); // Thumbnail (default 150px x 150px max)

	3-> wp_get_attachment_image_src( get_post_thumbnail_id(), 'large'); //This Function is getting the path of image
Topic 5
	How to add logo in the header 
	1-> use add_theme_support('custom-header') function in functions.php for getting header option in admin side

	2-> get_header_image() use this function for showing logo image, This function is return the path of the logo image

Topic 6
	How to show posts in front side
	1-> create a page like blog 

	2-> navigate to settings->reading and select post page (The post page is loads by default index.php)

	3-> use while loop and in the while loop use have_posts() and after loop started write the_post(); for counting post
		Ex. <?php
				while(have_posts()){
					the_post();
			?>
				Your HTML Design
			<?php } ?>

	4-> Usefull Functions 
		(1) the_title() -> for showing title of the post;
		(2) wp_get_attachment_image_src(get_post_thumbnail_id(),image size) -> for showing post image;
		(3) the_post_thumbnail() -> for showing post image same as wp_get_attachment_image_src;
		(4) the_date() -> for showing post created date;
		(5) get_the_date() -> for showing post created date but it's uses echo;
		(6) the_excerpt() -> for showing short description of the post;

Topic 7
	How to add pagination to blogs
	(1) Set minimum blogs showing from settings->reading;
	(2) Install WpPagenavi plugin;
	(3) use wp_pagenavi() for showing pagination and use echo before function;
	(4) add wp_head() function in header.php and add wp_footer() function in footer.php for plugin's css and js;

Topic 8
	How to show post details 
	(1) Create a single.php file on your theme folder (The single.php file is showing the post's content and details);
	(2) fist you add a button or a link like read more in your post's card use the_permalink() function for getting the link of your post
	(3) in the single.php you can use same functions as the page like Note: use the_post() in the upper side of single.php
		ex.
			the_title() -> for showing post title;
			the_content() -> for showing the post content;
			wp_get_attachment_image_src(get_post_thumbnail_id(),size) -> for showing post featured image;
			the_date() or get_the_date() -> for showing date of post;
			the_author() -> for showing th eauthor of post;
