HOW TO CREATE A CUSTOM THEME IN WORDPRESS

==================================================
TOPIC 1: HOW TO CREATE A CUSTOM THEME
=====================================

1. Create a Folder

Create a new folder inside:

xampp/htdocs/Your-WordPress-Folder/wp-content/themes/

Example:
mytheme

2. Create Two Files

Create these two files inside your theme folder:

i) style.css
Use: For theme information and CSS styling.

ii) index.php
Use: Main/default template file of the theme.

3. Add Theme Information in style.css

/*
Theme Name: My Theme
Author: BCA Sem 3
Description: My Custom WordPress Theme
Version: 1.0
*/

4. Add Theme Code

Add your HTML/PHP theme code inside index.php.

## USEFUL FUNCTIONS

1. echo get_template_directory_uri();

Use:
Returns the URL/path of the current theme directory.

Example:
echo get_template_directory_uri();

2. bloginfo('template_directory');

Use:
Displays the URL/path of the current theme directory.

3. get_header();

Use:
Includes the header.php file in the current template.

Example:

<?php get_header(); ?>

4. get_footer();

Use:
Includes the footer.php file in the current template.

Example:

<?php get_footer(); ?>

5. get_sidebar();

Use:
Includes the sidebar.php file in the current template.

Example:

<?php get_sidebar(); ?>

6. site_url();

Use:
Returns the URL of the WordPress website.

Example:
echo site_url();

NOTE:
Create header.php and footer.php files in your theme folder.

Use get_header() and get_footer() in index.php to include them.

Example:

<?php get_header(); ?>

<!-- Page Content -->

<?php get_footer(); ?>

TOPIC 2: HOW TO MAKE HEADER MENU DYNAMIC
========================================

1. Create functions.php

Create a functions.php file in your theme folder.

Use register_nav_menus() to register a menu location.

Example:

register_nav_menus(
array(
'primary-menu' => 'Header Menu'
)
);

Note:
The array key is the menu location.
The value is displayed in the WordPress Admin Dashboard.

2. Create Menu from Admin Dashboard

Go to:

WordPress Admin Dashboard -> Appearance -> Menus

Create and edit your menu.

3. Display Menu in header.php

Use wp_nav_menu():

<?php
wp_nav_menu(
    array(
        'theme_location' => 'primary-menu',
        'menu_class' => 'menu'
    )
);
?>

4. Design the Menu

wp_nav_menu() generally generates <ul> and <li> elements.

You can design the menu using CSS.

Example:

.menu {
/* Your CSS */
}

TOPIC 3: HOW TO CREATE CUSTOM PAGE LAYOUT
AND SHOW PAGES DYNAMICALLY
==========================

1. Create page.php

Create a page.php file in your theme folder.

WordPress uses this template for displaying pages.

2. Include Header and Footer

<?php get_header(); ?>

<!-- Page Content -->

<?php get_footer(); ?>

3. Display Page Title

Use:

<?php the_title(); ?>

Use:
Displays the title of the current page.

4. Display Page Content

Use:

<?php the_content(); ?>

Use:
Displays the content of the current page.

If required, use the_post() before displaying page data:

<?php
the_post();
the_title();
the_content();
?>

5. get_the_content()

Use:

<?php echo get_the_content(); ?>

Use:
Returns the content of the current post or page.

Note:
get_the_content() returns the content, so echo is generally used.

TOPIC 4: HOW TO ADD FEATURED IMAGE / THUMBNAIL
==============================================

1. Enable Featured Image

Add this in functions.php:

add_theme_support('post-thumbnails');

Use:
Enables the Featured Image option in the WordPress Admin Dashboard.

2. Display Featured Image

Use:

<?php the_post_thumbnail(); ?>

You can specify image sizes:

the_post_thumbnail('thumbnail');
the_post_thumbnail('medium');
the_post_thumbnail('large');
the_post_thumbnail('full');

Image Sizes:

thumbnail
Use: Default thumbnail size, normally 150 x 150.

medium
Use: Medium image size, normally 300 x 300.

large
Use: Large image size, normally 1024 x 1024.

full
Use: Original image resolution.

Custom Image Size:

<?php the_post_thumbnail(array(100, 100)); ?>

Use:
Displays the featured image with custom dimensions.

NOTE:
When using the_post_thumbnail(), you do not need to manually use an <img> tag.

3. Get Featured Image URL

Use:

<?php
$image = wp_get_attachment_image_src(
    get_post_thumbnail_id(),
    'large'
);
?>

Use:
Gets information about the featured image, including its URL and dimensions.

TOPIC 8: HOW TO ADD PAGINATION TO BLOG
======================================

1. Set Number of Posts

Go to:

Settings -> Reading

Set the number of posts that should be displayed per page.

2. Install WP-PageNavi Plugin

Install and activate the WP-PageNavi plugin.

3. Display Pagination

Use:

<?php wp_pagenavi(); ?>

Use:
Displays pagination for posts when using the WP-PageNavi plugin.

4. Add WordPress Header and Footer Hooks

Add this inside header.php before </head>:

<?php wp_head(); ?>

Add this inside footer.php before </body>:

<?php wp_footer(); ?>

Use of wp_head():
Outputs scripts, styles, metadata, and other required content in the <head> section.

Use of wp_footer():
Outputs scripts and other required content before the closing </body> tag.

These hooks allow WordPress and plugins to load their required CSS, JavaScript, and other resources.

TOPIC 10: HOW TO SHOW COMMENT FORM ON BLOG DETAIL PAGE
======================================================

1. Display Comment Form

Use:

<?php comment_form(); ?>

Use:
Displays the WordPress comment submission form.

2. Display Comments

Use:

<?php wp_list_comments(); ?>

wp_list_comments([
    'style'              => 'ol',
    'avatar_size'        => 50,
    'short_ping'         => true,
    'type'               => 'all',
    'reverse_top_level'  => false,
    'reverse_children'   => false,
    'callback'           => 'my_custom_comment',
]);

| Argument            | Use                                                                                                |
| ------------------- | -------------------------------------------------------------------------------------------------- |
| `style`             | Defines the HTML structure used to display comments. Values can be `ol`, `ul`, or `div`.           |
| `avatar_size`       | Sets the size of the comment author's avatar in pixels.                                            |
| `short_ping`        | Displays pingbacks in a shorter format when set to `true`.                                         |
| `type`              | Specifies which type of comments to display, such as `all`, `comment`, `pingback`, or `trackback`. |
| `reverse_top_level` | Reverses the order of top-level comments when set to `true`.                                       |
| `reverse_children`  | Reverses the order of replies/child comments when set to `true`.                                   |
| `callback`          | Allows you to create a custom function to control the HTML/design of each comment.                 |
| `end-callback`      | Allows you to run a custom function after each comment's children/replies have been displayed.     |
| `page`              | Specifies the page number of comments to display.                                                  |
| `per_page`          | Specifies how many comments should be displayed per page.                                          |
| `max_depth`         | Sets the maximum depth/level of nested comments and replies.                                       |

function my_custom_comment($comment, $args, $depth)
{
    ?>
    
    <li class="custom-comment">

        <h4>
            <?php echo get_comment_author(); ?>
        </h4>

        <p>
            <?php comment_text(); ?>
        </p>

        <small>
            <?php comment_date(); ?>
        </small>

    </li>

    <?php
}

wp_list_comments([
    'callback' => 'my_custom_comment'
]);

Use:
Displays the comments and replies for the current post.

3. Display Comments and Comment Form Together

Use:

<?php comments_template(); ?>

Use:
Loads the theme's comments.php file to display comments and the comment form.

If you use comments_template() in single.php, you normally do not need to separately call comment_form() there.

Example of comments.php:

<?php
wp_list_comments();
comment_form();
?>

IMPORTANT WORDPRESS TEMPLATE FILES
==================================

style.css
Use: Contains theme information and CSS styling.

index.php
Use: Default/fallback template file.

header.php
Use: Contains the website header.

footer.php
Use: Contains the website footer.

sidebar.php
Use: Contains the website sidebar.

functions.php
Use: Contains theme functions and enables theme features.

page.php
Use: Displays pages.

single.php
Use: Displays individual blog posts.

comments.php
Use: Displays the comments section.

archive.php
Use: Displays archive pages.

search.php
Use: Displays search results.

404.php
Use: Displays the 404 error page.

    Use: Displays a registered navigation menu on the front end.

    Use: Registers one or more navigation menu locations for the theme.

16. add_theme_support()
    Use: Enables specific WordPress features in the theme, such as featured images and custom headers.

    Use: Displays the comments and replies for the current post.

22. bloginfo('template_directory')
    Use: Displays the URL of the current theme directory.

23. wp_head()
    Use: Outputs scripts, styles, metadata, and other content in the <head> section.

24. wp_footer()
    Use: Outputs scripts and other required content before the closing </body> tag.

25. get_header_image()
    Use: Returns the URL of the custom header image.

26. wp_get_attachment_image_src()
